TAFK Key Routes

A key you press passes through the Defy's firmware, then Windows, then WezTerm, then tmux, before the program in the pane sees it. Any layer can take the key, rewrite it, or let it through. This map traces every bound chord through every layer to eight pane programs, shows what each chord costs your hands, and checks that sibling programs answer the same intent with the same key. The search finds any key, alias or command, as keys does in the shell.

    Same intent, same key?

    Each row is one thing you do in several programs. The TAFK column is the key the rest of the setup uses for it, with what it costs your hands. Amber marks a program that answers on a different key; red marks one with no key at all, and the line beneath says what the TAFK key does there instead. Amber-outlined keys only work because the terminal can't tell them from the real key; dashed ones work because tmux rewrites them.

    Broken keys

    A program or layer advertises each of these, but pressing it does something else, or nothing, or no key on the Defy can send it.

    Rewritten on purpose

    tmux rewrites these for one program so a key keeps its TAFK meaning. The program's own binding is lost, but the intent survives on another key.

    Hidden by design

    Stock program keys that an outer layer takes on purpose. Alt belongs to tmux and Ctrl+A is its prefix, so these are the price of instant pane and window movement. They're listed so you can see when a new program's default is about to vanish.

    How this was built

    bin/keys reads the checkout: configs/keyboard/dygma-defy.json (a Bazecor backup), wezterm.lua under nvim -l, tmux's list-keys from a private server, bash bind -p, Neovim's keymaps, and the agents' defaults saved in configs/keymap/defaults with your config on top. Windows' own shortcuts are a fixed list. How each program hears keys comes from live panes. What each entry does comes from beside it (a tmux bind -N note, a comment, a desc) or from configs/keymap/notes.toml.

    Not verified: whether WezTerm hands tmux every chord distinctly, and which of Claude's Chat and Scroll contexts wins Shift+↑/↓.
